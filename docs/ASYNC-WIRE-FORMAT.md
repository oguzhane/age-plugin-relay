# Async (Control Tower) Wire Format Reference

Complete HTTP request/response bodies for the async flow. All interactions use `POST` with `Content-Type: application/json`. Every request body is a `RelayRequest` (same Go struct, different fields populated per action).

Three actors: **Plugin**, **Broker**, **Operator**.

---

## 1. Plugin → Broker: submit intent

**Action:** `unwrap`

### Request

```json
{
  "version": 1,
  "action": "unwrap",
  "stream": false,
  "intent_id": "a3f12c4e8b9d6f0a1b2c3d4e5f6a7b8c",
  "tag": "QPg24g",
  "expires_at": 1715350800,
  "encrypted_payload": "<base64: age-encrypted InnerRequestPayload>"
}
```

| Field | Type | Description |
|---|---|---|
| `version` | int | Always `1` |
| `action` | string | `"unwrap"` |
| `stream` | bool | Optional. Ignored by broker (only used in sync flow) |
| `intent_id` | string | 16 random bytes, hex-encoded (32 chars). Generated by plugin |
| `tag` | string | `base64(SHA-256(unwrap_recipient)[:4])`. Routing tag for operator pull |
| `expires_at` | int64 | Unix timestamp (seconds). Plugin sets `now + timeout` |
| `encrypted_payload` | string | Base64 age ciphertext. Encrypted to operator's recipient. Opaque to broker |

#### Inside `encrypted_payload` (decrypted by operator only)

```json
{
  "nonce": "deadbeef01020304deadbeef01020304",
  "outer_hash": "<SHA-256 hex, 64 chars>",
  "expires_at": 1715350800,
  "stanzas": [
    {
      "type": "X25519",
      "args": ["ephemeral-share"],
      "body": "<base64 raw std>"
    }
  ],
  "ephemeral_key": "age1qqnv7...plugin's ephemeral public key..."
}
```

`outer_hash` = `SHA-256("1.unwrap.a3f12c4e8b9d6f0a1b2c3d4e5f6a7b8c.QPg24g.1715350800")`

### Response — 202 Accepted

```json
{}
```

### Response — 409 Conflict (duplicate intent_id)

```json
{
  "error": "duplicate_intent"
}
```

### Response — 400 Bad Request (missing fields)

```json
{
  "error": "missing intent_id"
}
```

## 2. Operator → Broker: pull pending intents

**Action:** `pull`

### Request

```json
{
  "version": 1,
  "action": "pull",
  "tag": "QPg24g"
}
```

| Field | Type | Description |
|---|---|---|
| `version` | int | Always `1` |
| `action` | string | `"pull"` |
| `tag` | string | Operator filters by this tag |

### Response — 200 OK

```json
{
  "intents": [
    {
      "intent_id": "a3f12c4e8b9d6f0a1b2c3d4e5f6a7b8c",
      "request": {
        "version": 1,
        "action": "unwrap",
        "intent_id": "a3f12c4e8b9d6f0a1b2c3d4e5f6a7b8c",
        "tag": "QPg24g",
        "expires_at": 1715350800,
        "encrypted_payload": "<base64: age-encrypted InnerRequestPayload>"
      }
    }
  ]
}
```

The `request` field is the **verbatim original** `RelayRequest` the plugin submitted. The broker stores the raw bytes and deserializes them back. The `intent_id` appears both at the top level (for convenience) and inside `request`.

If no pending intents match the tag:

```json
{
  "intents": []
}
```

## 3. Operator → Broker: fulfill

**Action:** `fulfill`

### Request

```json
{
  "version": 1,
  "action": "fulfill",
  "intent_id": "a3f12c4e8b9d6f0a1b2c3d4e5f6a7b8c",
  "encrypted_payload": "<base64: age-encrypted InnerResponsePayload>"
}
```

| Field | Type | Description |
|---|---|---|
| `version` | int | Always `1` |
| `action` | string | `"fulfill"` |
| `intent_id` | string | The intent being fulfilled |
| `encrypted_payload` | string | Base64 age ciphertext. Encrypted to plugin's ephemeral recipient. Opaque to broker |

#### Inside `encrypted_payload` (decrypted by plugin only)

```json
{
  "nonce": "1a2b3c4d5e6f7a8b1a2b3c4d5e6f7a8b",
  "outer_hash": "<SHA-256 hex, 64 chars>",
  "file_key": "<base64 raw std: 16-byte age file key>"
}
```

`outer_hash` = `SHA-256("fulfill.a3f12c4e8b9d6f0a1b2c3d4e5f6a7b8c")`

### Response — 200 OK

```json
{
  "status": "ok"
}
```

### Response — 404 Not Found

```json
{
  "error": "unknown_intent"
}
```

### Response — 409 Conflict

```json
{
  "error": "intent_already_terminal"
}
```

## 5. Plugin → Broker: poll

**Action:** `poll`

### Request

```json
{
  "version": 1,
  "action": "poll",
  "intent_id": "a3f12c4e8b9d6f0a1b2c3d4e5f6a7b8c"
}
```

| Field | Type | Description |
|---|---|---|
| `version` | int | Always `1` |
| `action` | string | `"poll"` |
| `intent_id` | string | The intent to check |

### Response — 200 OK (pending)

```json
{
  "status": "pending"
}
```

### Response — 200 OK (fulfilled)

```json
{
  "status": "fulfilled",
  "encrypted_payload": "<base64: age-encrypted InnerResponsePayload>"
}
```

The `encrypted_payload` is the exact blob the operator submitted in the fulfill request.

### Response — 200 OK (rejected)

```json
{
  "status": "rejected"
}
```

### Response — 404 Not Found (expired or unknown)

```json
{
  "error": "unknown_intent"
}
```

## Sync Flow Comparison

In the sync flow (relay-server, not broker), the plugin sends the same `unwrap` request structure directly to the relay-server. The relay-server decrypts, unwraps, and responds immediately:

### Sync response — 200 OK (JSON)

```json
{
  "encrypted_payload": "<base64: age-encrypted InnerResponsePayload>"
}
```

The inner response payload is identical in structure but the `outer_hash` uses action `"unwrap"`:

`outer_hash` = `SHA-256("unwrap.<intent_id>")`

### Sync response — 200 OK (SSE)

```
: heartbeat

event: result
data: {"encrypted_payload": "<age-encrypted blob>"}

```

### Sync error responses

```json
{
  "error": "description of error"
}
```

## Go Types

All actors use the same `RelayRequest` struct for all actions (fields are `omitempty`):

```go
// relay/client.go
type RelayRequest struct {
    Version          int    `json:"version"`
    Action           string `json:"action"`
    Stream           bool   `json:"stream,omitempty"`
    IntentID         string `json:"intent_id,omitempty"`
    Tag              string `json:"tag,omitempty"`
    ExpiresAt        int64  `json:"expires_at,omitempty"`
    EncryptedPayload string `json:"encrypted_payload,omitempty"`
}
```

Broker response types:

```go
// relay/broker/types.go
type AsyncAccepted struct{}                          // 202 body: {}

type PullResponse struct {
    Intents []PullIntent `json:"intents"`
}

type PullIntent struct {
    IntentID string       `json:"intent_id"`
    Request  RelayRequest `json:"request"`            // verbatim original plugin request
}

type PollResponse struct {
    Status           string `json:"status"`            // "pending" | "fulfilled" | "rejected"
    EncryptedPayload string `json:"encrypted_payload,omitempty"`
}
```

Plugin-side poll response (mirrors broker's `PollResponse` with an extra `error` field):

```go
// relay/client.go
type asyncPollResponse struct {
    Status           string `json:"status"`
    EncryptedPayload string `json:"encrypted_payload,omitempty"`
    Error            string `json:"error,omitempty"`
}
```

Sync response:

```go
// relay/client.go
type RelayResponse struct {
    EncryptedPayload string `json:"encrypted_payload,omitempty"`
    Error            string `json:"error,omitempty"`
}
```

Inner payloads (encrypted, opaque to broker):

```go
// relay/payload.go
type InnerRequestPayload struct {
    Nonce        string        `json:"nonce"`
    OuterHash    string        `json:"outer_hash"`
    ExpiresAt    int64         `json:"expires_at"`
    Stanzas      []RelayStanza `json:"stanzas"`
    EphemeralKey string        `json:"ephemeral_key"`
}

type InnerResponsePayload struct {
    Nonce     string `json:"nonce"`
    OuterHash string `json:"outer_hash"`
    FileKey   string `json:"file_key"`
}

type RelayStanza struct {
    Type string   `json:"type"`
    Args []string `json:"args"`
    Body string   `json:"body"`
}
```

## Outer Hash Summary

| Direction | Formula | Example |
|---|---|---|
| Request (plugin → server/operator) | `SHA-256("{version}.{action}.{intent_id}.{tag}.{expires_at}")` | `SHA-256("1.unwrap.a3f1...7b8c.QPg24g.1715350800")` |
| Sync response (server → plugin) | `SHA-256("unwrap.{intent_id}")` | `SHA-256("unwrap.a3f1...7b8c")` |
| Async response (operator → plugin) | `SHA-256("fulfill.{intent_id}")` | `SHA-256("fulfill.a3f1...7b8c")` |
